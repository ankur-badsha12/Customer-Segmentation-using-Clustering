Customer Segmentation Using Clustering

📌 Project Overview :


The main objective is to analyze customer data, identify different customer groups based on their characteristics and behavior, and generate useful business recommendations.

The project uses Python and machine learning-based clustering to perform customer segmentation.

🎯 Objectives :
Understand customer behavior
Perform Exploratory Data Analysis (EDA)
Identify different customer groups
Apply K-Means clustering
Find the suitable number of clusters using the Elbow Method
Visualize customer segments
Generate business insights and recommendations

These objectives are aligned with the task requirements.

🤖 Customer Segmentation :

K-Means Clustering

K-Means clustering was used to divide customers into groups with similar characteristics.

The features used for clustering were selected based on the available customer dataset.

Before applying K-Means, the selected features were scaled using StandardScaler.

📉 Elbow Method :

The Elbow Method was used to determine a suitable number of customer clusters.

The method compares different values of K and uses the model's inertia to identify an appropriate number of clusters.

The task specifically includes the Elbow Method as part of the customer segmentation process and interview preparation.


💡 Business Insights :

After creating the clusters, each customer segment was analyzed based on characteristics such as:

Income

The segments can then be interpreted into meaningful business groups, such as:

Premium Customers
